# Literature Review

Audited literature survey for **Predictive Digital Twin for Data Centre Thermal Management** (`27` numbered entries + errata note).

Verification status counts: `3` `read-full` (#1, #3, #6), `1` `read-partial` (#2), `4` `abstract-only` (#4, #5, #7, #8), `12` `reference-list-only` (#9–10, #17–21, #23–27), `7` `unverified` (#11–16, #22). Numbers are quoted only from `read-full` or `read-partial` sources checked directly in the project brief.
